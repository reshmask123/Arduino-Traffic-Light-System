# 🚦 Arduino Traffic Light System

This project is a simple traffic light system designed using an Arduino Uno and simulated in Tinkercad. It uses three LEDs — red, yellow, and green — to represent a real traffic signal.

The Arduino controls each LED in a specific sequence with different time delays. This project demonstrates basic Arduino programming, digital output control, and electronic circuit connections.

## 🛠️ Components Used
- Arduino Uno R3
- Red LED
- Yellow LED
- Green LED
- 220Ω Resistors
- Breadboard
- Jumper Wires

## 💡 Working
The traffic lights operate in the following sequence:

**Red → Yellow → Green → Yellow → Repeat**

This project was created as a beginner electronics project using Tinkercad.
